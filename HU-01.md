HU-01: Restringir CORS en autenticación
Origen
H-AUTH-05 — Hallazgo pendiente: eliminar CORS permisivo (/.*/) y definir la allowlist por entorno con el propietario del despliegue. Evidencia: auth/src/main/java/com/bcp/workshop/auth/JwtTokenService.java:37-42; auth/src/main/resources/application.properties:4-9.
Contexto
El secreto de firma del JWT ya está externalizado. El pendiente de este hallazgo es restringir CORS; no se incluyen secretos ni cambios al token.
Ajustes necesarios
Obtener del propietario del despliegue la allowlist correspondiente a cada entorno.
Reemplazar la configuración CORS permisiva por la allowlist acordada para cada entorno.
Criterios de aceptación
La configuración de cada entorno define explícitamente una allowlist de orígenes; una prueba de configuración verifica que no se use /.*/.
Una prueba HTTP verifica que un origen incluido en la allowlist recibe el encabezado CORS correspondiente.
Una prueba HTTP verifica que un origen no incluido no recibe autorización CORS.
Evidencia esperada
Salida de las pruebas de configuración y HTTP para orígenes permitidos y no permitidos.
Configuración CORS actualizada y revisada para los entornos aplicables.
